# Tarini Kavuturu — Portfolio

A static, responsive portfolio focused on business analysis, product and business operations, analytics, and technical systems.

## Run locally

Open `index.html` directly, or serve this folder with any static file server.

## Structure

- `index.html` — portfolio home page
- `projects/` — dedicated project case studies
- `assets/images/` — portrait, dashboard, and project evidence
- `assets/reports/` — supporting APB project report
- `assets/resumes/` — downloadable resume variants
- `styles.css` — shared responsive design system
- `script.js` — current year and skill filtering

All project claims are limited to the supplied source material. The ultrasonic case study explicitly notes that original visual evidence was not provided.
